같이가개 개인정보 처리방침

같이가개(이하 "앱")는 반려견과 차로 이동하는 보호자를 돕는 차량용 앱입니다. 이 방침은 앱이 어떤 정보를 어디에, 얼마 동안 두고, 누구에게 보내는지 설명합니다.

근거 표: data_inventory.md

  • 시행일: 2026-11-13
  • 버전: 1.0 (앱 1.0.0 기준)

1. 한눈에 보기

  • 회원 가입·로그인이 없습니다. 이름·전화번호·이메일을 받지 않습니다.
  • 위치 정보를 저장하지 않습니다. 앱에는 위치 권한이 없습니다. 차량 기본 내비가 알려 주는 현재 위치와 목적지는 화면 안내와 근처 장소 조회에만 쓰고, 기기에도 서버에도 저장하지 않습니다.
  • 반려견 프로필·이동 기록은 차량 기기에 저장됩니다. 보호자가 동의하고 보낼 때만 일부(아래 4장)가 전송됩니다.
  • 광고·분석·오류 보고 도구를 쓰지 않습니다.
  • 앱 1.0.0 제출본은 개발사 서버에 연결하지 않습니다. 보호자 폰 대기 페이지, 도착 예정 공유, 동물병원 사전 접수처럼 서버가 필요한 기능은 서버가 연결된 경우에만 동작합니다. 이 방침은 그 경우까지 포함해 설명합니다.

2. 처리하는 정보와 목적

정보목적저장 위치보관 기간
반려견 프로필 (최대 3마리. 이름, 크기, 나이, 흔들림에 예민한 정도(보호자 응답), 배변 간격, 원하는 시설), 오늘 타는 아이 선택쉼표(휴식) 시각·장소 추천, 화면 표시차량 기기이용자가 삭제할 때까지
이동 기록 (주행 시간, 휴식 수, 주행 자극 최고값과 5분 간격 값, 관찰 신고 요약)도착 후 기록 리포트, 개인 맞춤 보정차량 기기이용자가 삭제할 때까지
개인 맞춤 보정 기록 (반려견별 최근 30개)주행 자극 예보를 반려견에 맞춤차량 기기반려견마다 최근 30개
반려견 사진 (보호자가 폰으로 올린 1장, 긴 변 512px로 줄여 저장)프로필·출발 전 화면 표시차량 기기이용자가 삭제할 때까지(프로필 지우기·내 데이터 삭제)
출발 체크 기억 (최근 3번 출발 때 체크한 항목만)[지난번과 같아요], 빠뜨린 항목 다시 강조차량 기기최근 3번
증상 메모 (직접 입력 또는 받아쓰기, 최대 120자)동물병원에 보여 줄 메모차량 기기이용자가 삭제할 때까지
차량 신호 (속도, 기어, 주차 브레이크, 문 열림, 실내 온도, 배터리, 주행 제한 상태)주행 중 안전 화면 전환, 휴식·도착·대기 안내저장하지 않음(앱 실행 중 메모리)—
음성"응/나중에", "네/아니요" 응답과 증상 메모 받아쓰기소리는 저장하지 않음. 응답 문장도 저장하지 않음(메모 받아쓰기만 위 증상 메모로 저장)—
현재 위치·목적지길 따라 휴게소·장소·근처 동물병원 조회저장하지 않음. 여행 이어하기용으로 목적지의 해시값(원래 값을 알 수 없는 값)만 기기에 최대 3시간3시간 또는 여행 끝

"주행 자극"은 차량 흔들림을 바탕으로 계산한 값이며, 반려견의 몸 상태를 재거나 진단하지 않습니다.

긴급 도움에서 고른 상황은 저장하거나 보내지 않습니다. 음성으로 말한 응급 신고는 이동 기록의 관찰 신고에 상황 이름("위험 물질 섭취" 등)만 남고, 말한 문장은 남기지 않습니다. 긴급 도움은 전화를 자동으로 걸지 않습니다.

3. 서버가 연결된 경우 서버에 저장되는 정보

정보목적보관 기간
기기 식별 토큰(무작위 값의 해시만 저장), 앱 버전요청 확인, 요청 수 제한마지막 이용 후 180일
대기 모드 상태 (제한 시간, 경과 시간, 배터리 %, 실내 온도, "돌아가는 중"과 누른 사람(보호자 1·2, 이름 없음))보호자 폰 대기 페이지링크 2시간, 만료 후 정리 때 삭제
도착 예정 공유·병원 사전 접수 내용 (반려견 이름, 병원 이름, 도착 예정 시각, 증상, 증상 메모, 오늘 이동 요약 한 줄, 병원 응답)보호자·병원이 링크로 확인링크 2시간, 만료 후 정리 때 삭제
반려견 사진 업로드 (사진 1장, 5MB 이하)보호자 폰에서 차로 사진 전달차가 받으면 바로 삭제. 받지 않으면 10분 뒤 만료, 정리 때 삭제
폰으로 받는 이동 기록 (탄 반려견 이름, 날짜·목적지 이름, 이동 시간·거리·휴식·관찰 신고 수, 타임라인, 주행 자극 5분 값, 병원에 보여 줄 요약. 위치 없음)보호자 폰에서 기록 보기링크 24시간, 만료 1일 뒤 정리 때 삭제
문장 다듬기 기록 (종류, 걸린 시간, 대체 여부. 문장 내용은 저장 안 함)품질 확인30일
접속 기록 (IP 주소, 요청 경로, 시각)장애 대응·보안지금(공모전 시연): 개발 PC의 서버 실행 창·로그 파일에만 남고 외부로 보내지 않음. 자동 삭제 없음 → 출시 전 보관 기간을 정해 자동 삭제를 넣는다
  • 위치 좌표는 서버에 저장하지 않습니다. 대기 공유·도착 예정 공유·병원 접수 요청은 좌표를 받지 않도록 막혀 있습니다.
  • 다만 근처 동물병원·장소를 찾을 때 보내는 현재 위치(좌표)는 지금 시연 서버의 접속 기록(IP 주소·요청 경로·시각)에 남습니다. 이 기록은 개발 PC에만 남고 외부로 보내지 않으며, 자동 삭제는 아직 없습니다. 출시 전 접속 기록에서 좌표를 빼고, 보관 기간을 정해 자동 삭제를 넣습니다.
  • 휴식 안내 문장을 다듬을 때는 서버 안의 문장 생성 모델로 휴게소 이름·도착까지 남은 분 같은 사실만 보냅니다. 반려견 이름과 위치는 보내지 않고, 외부 인공지능 회사로도 보내지 않습니다.

4. 제3자 제공

보호자가 동의할 때만, 링크를 받은 사람이 볼 수 있습니다. 개발사가 병원이나 다른 회사에 직접 보내지 않습니다.

받는 사람보이는 내용언제동의 방법
보호자(링크·QR을 연 사람) — 대기 페이지제한·경과 시간, 배터리, 실내 온도(측정값이 있을 때)대기 모드 중"잠깐 다녀올게" 후 보호자가 QR을 찍음
보호자 — 도착 예정 페이지반려견 이름, 병원 이름, 도착 예정, 증상·메모·오늘 요약(함께 보내기를 켠 경우)링크를 만든 뒤 2시간동물병원 화면에서 링크 만들기
제휴 동물병원 — 사전 접수함위와 같은 내용 + 병원 응답 칸사전 접수 후 2시간정차 중: 보낼 내용을 확인하고 "동의하고 보내기". 주행 중: "○○에 증상과 도착 예정을 보낼까요?"에 "네"라고 답할 때만
보호자(링크·QR을 연 사람) — 이동 기록 페이지위 "폰으로 받는 이동 기록" 내용링크를 만든 뒤 24시간도착 요약에서 [폰으로 기록 받기]를 누름
두 번째 보호자 — 대기 페이지대기 페이지와 같은 내용, "돌아가는 중"을 누른 사람은 이름 없이 보호자 1·2로만대기 모드 중설정 시트의 "보호자 2" QR을 찍음
  • 사전 접수는 앱과 연동된 제휴 동물병원에만 합니다. 현재는 시연용 제휴 동물병원뿐입니다.
  • 그 밖의 동물병원에는 아무것도 보내지 않습니다. 전화 연결만 안내합니다.

다른 회사가 처리하는 정보

  • 음성 인식: 말소리는 차량에 설치된 시스템 음성 인식 서비스가 처리합니다. 그 서비스의 개인정보 처리방침이 적용됩니다.
  • 차량 신호·길 안내: 차량 플랫폼(Pleos)의 기본 기능에서 받습니다.
  • 장소 사진: 서버가 연결된 경우 한국관광공사 서버에서 바로 불러오며, 이때 기기의 IP 주소가 그 서버에 전달됩니다.

5. 이용자의 권리와 삭제 방법

  • 모두 삭제: 설정 → 개인정보 → "내 데이터 삭제". 기기의 프로필·이동 기록·메모·보정 기록을 지우고, 서버가 연결돼 있으면 서버의 공유 기록과 기기 토큰도 지웁니다.
    • 서버에 연결되지 않으면 다음 연결 때 다시 지웁니다.
    • 공공데이터 휴게소 목록과 사진 캐시는 개인정보가 아니어서 남습니다.
  • 맞춤 보정만 지우기: 설정 → "맞춤 초기화".
  • 앱 삭제: 기기 백업을 하지 않으므로 앱을 지우면 기기의 정보도 모두 지워집니다.
  • 마이크 권한: 언제든 끌 수 있습니다. 끄면 버튼으로만 응답합니다.
  • 열람·정정·삭제 요청이나 문의는 아래 문의처로 보내 주세요. 회원 정보가 없으므로 서버 기록은 기기에서 "내 데이터 삭제"로 지우는 것이 가장 확실합니다.

6. 안전 조치

  • 공유 링크는 추측하기 어려운 무작위 값입니다. 서버에는 그 해시만 저장하고, 2시간 뒤 만료됩니다.
  • 공유 페이지는 검색 엔진에 노출되지 않게 표시하고, 외부 스크립트를 불러오지 않습니다.
  • 기기당 분당 요청 수를 제한합니다.

7. 아동의 개인정보

앱은 아동의 개인정보를 받지 않습니다.

8. 문의처

  • 개인정보 보호 책임자: 같이가개 개발자(문의는 아래 고객 지원으로)
  • 고객 지원·문의: GitHub Issues(저장소 Issues 탭). 이메일·전화는 받지 않습니다.
