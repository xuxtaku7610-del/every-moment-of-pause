# 스타일 v4 — 차량 디스플레이 (최종 기준, v2·v3를 덮어씀)

기준 시안: `v4/v4-drive.png`, `v4/v4-pause.png` (원본 `v4/v4.html`). v3(토스풍)는 폐기. 나머지 15개 화면은 아래 규칙으로 v2 레이아웃을 다시 칠한다.

## 원칙 (피드백 반영)
1. **무채색 + 강조색 1개.** 강조색 `accent #1F7A6E`는 경로선·다음 쉼표·추천 표시에만. 경고색 `warn`은 피로 주의·기상 알림에만. 나머지는 흑백 회색.
2. **평평하게.** 그림자·그라데이션·입체감 없음. 카드는 흰 면 + 1dp(2px) 테두리 `line`.
3. **작은 모서리, 하나의 규칙.** 카드 16dp, 버튼·칩 12dp. 알약형·큰 둥글기 금지.
4. **지도 위에 떠 있는 카드.** 주행 화면은 지도(경로 도식)가 바탕이고, 정보 카드는 왼쪽에 떠 있다. 차량 디스플레이 문법.
5. **글자 위계는 크기로, 굵기는 절제.** 큰 숫자는 가늘게(Light 200~300), 이름은 SemiBold 600, 본문 Regular/Medium. 굵기 800 금지.
6. **아이콘은 선 아이콘(1.8dp 선) 흑색 하나.** 색 아이콘 상자 금지.

## 컴포넌트
| 컴포넌트 | 규칙 |
| --- | --- |
| `RouteMap` | **경로 도식 지도**: 실제 지도 타일을 쓰지 않는다. NaviHelper 경로 좌표(또는 시뮬레이터 경로)를 화면 좌표로 투영해 흰 도로(30dp) 위에 `accent` 경로선(12dp)을 그린다. 주변 도로·블록은 장식용 단색 면. 현재 위치 = 흰 원(92dp, 테두리 `line`) 안 검은 진행 화살표, 진행 방향으로 회전. 다음 쉼표 = `accent` 핀(96×104dp, 흰 쉼표) + 옆 흰 라벨 카드 |
| `NextStopPanel` | 왼쪽 떠 있는 카드(640dp 폭, 화면 높이 꽉). 위→아래: "다음 쉼표"(쉼표 아이콘+24sp) → 이름 60sp → 노선·방향 → 분 168sp Light + 거리 36sp → 구분선 → "여기서 함께 해결돼요" + 목록(선 아이콘 + 항목 + 오른쪽 보조값, 64dp 행, 최대 4행) → 아래 고정 버튼 2개(주: `ink` 배경 흰 글자, 보조: `#F4F4F4`) + 음성 힌트 |
| `TripProgress` | 하단 떠 있는 카드: 위 줄 "출발지 출발 / 목적지 N시간 N분 남음", 아래 8dp 진행 바(지나온 구간 `ink`) + 현재 위치 원 + 쉼표 표시(다음 쉼표 `accent`, 이후 `ink3`) |
| `StatusChip` | 지도 위 오른쪽 위 흰 칩(64dp): 피로 점·수치·단계. 주의일 때만 점이 `warn` |
| `BatteryHero` | 숫자 220sp ExtraLight, 16dp 막대(`ink`) + 목표 지점 세로선과 "목표 80%"(`accent`), 아래 3칸 사실(남은 시간 / 완료 예상 / 충전 속도), 하단 차량 옆모습 선화 + 충전 케이블(`accent`) |
| `FamilyTimeline` | 흰 카드. 시간축(지금/10분/20분/끝) + 행: 선 아이콘 + 이름 + 오른쪽 길이, 아래 12dp 트랙에 막대(`ink`, 추천 행만 `accent` + "추천" 테두리 태그). 기상 알림 위치에 `warn` 점선. 마지막 행 "출발 준비" 막대만 `warn` |

## 다른 화면에 적용
- **출발 준비**: 오른쪽 절반 `RouteMap`(오늘 경로 + 쉼표 핀 2개), 왼쪽 `NextStopPanel` 자리에 멤버 목록(선 아이콘 행) + 수면 시간(12dp 모서리 버튼 5개) + `이대로 출발`.
- **제안 없음**: `RouteMap` 그대로, 왼쪽 카드에 "지금은 편안해요"(60sp) + 다음 예정 쉼표 + 피로 수치. 버튼 없음.
- **긴급**: 왼쪽 카드 맨 위에 `alert` 띠(높이 12dp)와 "피로 위험 86" → "지금 쉬어야 해요" → 가장 가까운 졸음쉼터·거리 → 주 버튼 `alert`. 지도의 핀도 `alert`.
- **음성**: 왼쪽 카드 하단 버튼 영역이 음성 상태로 바뀜(파형 막대 `ink`, "듣고 있어요"). 화면 전체를 덮지 않는다.
- **오프라인**: 지도 위 상단 칩 "저장된 정보로 안내 중"(회색 점).
- **파워냅**: 어두운 예외 유지(다크 토큰 + 링 `accent`), 장작 그림은 선화+주황 불꽃 하나로 단순화.
- **여행 리포트**: 왼쪽 카드 = 요약 문장(40sp SemiBold, 쉼표만 `accent`) + 3칸 사실 + 쉼표 기록 목록. 오른쪽 = 오늘 경로 `RouteMap` + 실제 쉼표 위치.
- **온보딩·설정**: 흰 카드 + 선 아이콘 목록 + 12dp 토글/세그먼트. 그림은 `RouteMap` 축소판.
- **1/2 창**: `NextStopPanel`만(지도 숨김). **1/3 창**: 분·이름·주 버튼만.

## 주행 중 규칙 (그대로)
텍스트 블록 2줄 이하, 버튼 2개 + 음성 힌트, 스크롤·자동 애니메이션 없음. 지도는 1초 단위 위치 갱신만(부드러운 이동 애니메이션 금지, 순간 이동).
