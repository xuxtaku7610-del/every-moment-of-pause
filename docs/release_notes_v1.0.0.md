# 같이가개 v1.0.0

반려견과 차로 이동하는 보호자를 위한 Pleos Connect(Android Automotive) 앱의 첫 공개 버전입니다. 공모전 1차 제출용 릴리스이며, 첨부 APK `gatigage-v1.0.0.apk`는 서버 없이 동작하는 오프라인 제출본입니다.

## 기능
- **주행 자극 예보** — 앞길에 굽은 길이 이어지면 숫자 없이 한 줄로 알립니다("3km 뒤 굽은 길 · 12분, 천천히 가면 덜 흔들려요"). 주행 자극은 차량 흔들림(가속·제동·회전) 기준이며 반려견을 잰 값이 아닙니다.
- **반려견 맞춤 쉼표** — 배변 간격·흔들림에 예민한 정도(보호자 응답)·운전 시간으로 휴게소 한 곳을 추천합니다. "응"이라고 말하거나 버튼을 누르면 기본 내비 경유지로 넣습니다(음성 8초 뒤 버튼).
- **콩이가 이상해요** — 주행 중 "콩이 토했어"처럼 말하면 한 줄 안내와 가장 가까운 정차 장소를 알려 줍니다. 응급 말이면 가까운 동물병원으로 안내합니다.
- **긴급 도움 (정차 중)** — 호흡 곤란·경련·의식 이상·외상·출혈·위험 물질 섭취 중 하나 또는 "바로 동물병원 찾기" → 가장 가까운 병원과 [경로 안내][전화](제휴 병원이면 [사전 접수]도). 전화는 자동으로 걸지 않습니다(번호·QR). 응급 안내 문구는 검수가 끝난 것만 보입니다(4장 모두 검수 끝).
- **잠깐 대기 모드** — 휴게소에서 "잠깐 다녀올게" → 차 화면이 창문 너머에서도 읽히는 큰 안내("주인이 곧 돌아와요", 영어 한 줄)로 바뀝니다. 실내 온도는 측정값이 있을 때만 보입니다.
- **콩이 내렸나요?** — 도착 후 P단에서 뒷문이 열리면 바로 묻습니다(문 신호만 사용).
- **도착 후 기록 리포트** — 총 이동 시간·거리·휴식·관찰 신고를 시간순으로, "주행 자극 자세히 보기"에서 그래프와 병원에 보여 줄 요약.
- 함께 가는 장소·동물병원 목록, 온보딩 3단계, 발표 모드(로고 5번 탭), 에뮬레이터 첫 실행 시연 주행 안내 띠([시연 주행 시작]).

## 설치
1. Pleos Connect 에뮬레이터(API 34) 또는 실차 환경을 준비합니다.
2. **이전에 디버그 앱을 설치했다면 먼저 지웁니다** — 서명이 달라 덮어쓰기가 되지 않습니다.
   ```powershell
   adb uninstall com.emop.pause
   ```
3. 설치하고 실행합니다.
   ```powershell
   adb install gatigage-v1.0.0.apk
   adb shell am start -n com.emop.pause/.MainActivity
   ```
4. 첫 실행은 온보딩 3단계입니다. 출발 전 화면 아래 띠의 [시연 주행 시작]을 누르면 pet-trip 시연 주행이 준비됩니다. 장면 이동은 로고를 3초 안에 5번 눌러 여는 발표 모드에서 고릅니다.

## 서버 없이 되는 것 / 서버가 필요한 것
| 이 APK만으로 되는 것 | 서버(`server/`)가 있어야 되는 것 |
| --- | --- |
| 주행 자극 예보, 쉼표 추천(내장 휴게소 샘플)·경유지 추가, 음성 응답(8초 → 버튼) | 휴게소 실제 데이터 갱신 |
| 콩이가 이상해요 안내, 긴급 도움(병원 목록은 내장 샘플) | 문장 다듬기(Ollama), 없으면 템플릿 문장 |
| 잠깐 대기 모드(차 화면), 도착 체크·문 이벤트 | 보호자 폰 대기 페이지·"돌아가는 중" |
| 도착 후 기록 리포트·개인 맞춤 조정(기기 저장) | 도착 예정 공유 링크, 병원 사전 접수·병원 접수함 |
| 함께 가는 장소·동물병원(내장 샘플, 전화번호 없음) | 함께 가는 장소 전국 327곳·동물병원 5,063곳 |

서버 실행은 README "5. 실행 방법"을 따릅니다. 이 APK는 서버 주소가 비어 있어 서버에 연결하지 않습니다(시연·서버 연동은 디버그 빌드).

## 알려진 제한
- 실차에서 아직 확인하지 않은 항목(실내 온도 값·단위, 문 위치 값의 뜻, 문자열 길이 제한, 1920×1080 배치 등): README [실차 확인 예정](../README.md#실차-확인-예정-2026-11-02-기준) 표.
- 주행 중 음성 신고는 에뮬레이터에 마이크가 없어 발표 모드·adb로 시연합니다.
- 돌봄·응급 카드(`content/care/`) 12장은 11/03 사용자 검수를 마쳤습니다(`reviewed: true`, 출처 Merck Veterinary Manual·RSPCA). 수의사 검수는 아니며, 안내는 일반 정보입니다.
- 병원 사전 접수는 "시연용 제휴 동물병원"(가상)만 됩니다. 실제 병원은 전화·도착 예정 링크만.
- 안내는 일반 정보이며 진료·응급 판단을 대신하지 않습니다.
