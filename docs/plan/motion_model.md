# 멀미 예보 모델 — `engine:motion` (CONCEPT 4장, F1)

> **정직한 표현.** 이 지수는 의학적 진단이 아니라 "주의 예보"다. 사람 대상 표준(ISO 2631-1)의 멀미 누적량 개념을 단순화해 차에 탄 반려견에게 **가정으로** 옮긴 것이며, 아래 계수는 모두 문헌을 참고한 가정값이다. 반려견 대상 검증 데이터는 없다. 화면·발표에서도 "멀미 주의 예보"라고만 말한다.

계수는 코드 한 곳(`engine/motion/.../MotionConstants.kt`)에만 있고, 이 문서와 주석에 근거를 같이 적는다.

## 1. 입력

| 입력 | 출처 | 없을 때 |
| --- | --- | --- |
| 속도 v (m/s) | AAOS `PERF_VEHICLE_SPEED` → `SignalSmoother`(3초 평균) | 계산 안 함(지수 유지) |
| 방위 ψ (도) | NaviHelper `CurrentLocationInfo.heading`, 시뮬레이터 | 경로 형상 곡률 사용 |
| 경로 형상 κ(s) (1/m) | 시연 GPX(`scenarios/geo/*.gpx`) → `RouteShape` | 횡가속 0 (종방향만) |
| 반려견 프로필 | 체급·나이·멀미 성향 (Room) | 보통 프로필 |

## 2. 가속도 추정
- 종방향: `a_x = Δv / Δt` (1초 간격, 잡음 처리한 속도).
- 횡방향: 방위가 있으면 `a_y = v · Δψ/Δt` (요 레이트, 라디안), 없으면 `a_y = v² · κ(s)`.
- 방위는 0/360 경계를 넘을 때 차이를 −180~180으로 접는다.

## 3. 대역 필터 (0.02~0.5Hz)
ISO 2631-1 부록 D의 멀미 주파수 가중(Wf)은 **수직** 진동 기준으로 0.1~0.5Hz 부근에 정점이 있다(CONCEPT 4장의 "0.1~0.5Hz"). 그런데 승용차의 멀미는 주로 **수평**(좌우·앞뒤) 흔들림이고, 수평 저주파 진동 실험에서는 0.2Hz 아래에서 가속도 기준 감수성이 거의 일정하다(Donohew & Griffin 2004). 고갯길의 좌우 교대는 커브 하나가 8~15초라 0.03~0.07Hz에 몰려 있어, 하한을 0.1Hz로 두면 정작 고갯길을 거의 걸러 버린다(시험: 50km/h·반경 100m·호 150m S자 7분에 지수 11).
- **결정(2026-10-29):** 축마다 **2차 버터워스 고역통과 0.02Hz + 2차 버터워스 저역통과 0.5Hz**(쌍선형 변환). CONCEPT보다 하한을 낮춘 것이다. 직류(한 방향으로 오래 도는 일정한 곡선·일정한 가속)는 여전히 거른다.
- 앱 신호는 1Hz라 나이퀴스트가 0.5Hz다. 그래서 저역통과 차단 주파수는 `min(0.5Hz, 0.45·fs)`로 잡고, 1Hz에서는 "1초 차분" 자체가 평균 필터 역할을 한다. 필터가 제대로 거르는지는 10Hz로 넣어 단위 테스트한다(F1-06).
- 고역통과 때문에 **한 방향으로 오래 도는 일정한 곡선**(직류 성분)이나 일정한 가속은 누적되지 않는다. 멀미를 부르는 것은 좌우로 반복되는 흔들림이다(고갯길 S자 커브, 가다 서다).
- 보정 확인(1Hz, 보통 프로필, 10분마다 지수): 50km/h·반경 100m·호 150m → 28·36·42·46·49·51 / 40km/h·반경 60m·호 80m → 29·38·44·48·51·54. 보통 프로필은 고갯길 25~30분에 주의(40)에 닿는다.

## 4. 누적량과 지수
- 축 합성: `a_w² = (k_x·a_x,f)² + (k_y·a_y,f)²`, `k_x = k_y = 1.0` (가정: 수평 두 축 같은 가중. ISO 2631-1의 멀미 평가는 수직축만 정의하므로 승용차 수평 흔들림에 옮긴 것은 가정).
- 누적: `D ← D·e^(−Δt/τ) + a_w²·Δt`. MSDV = √D (m/s^1.5). ISO 2631-1의 MSDV = (∫a_w² dt)^½을 그대로 쓰되 회복을 넣으려고 누설(leak)을 둔다.
  - 주행 중 `τ_drive = 120분` (적응: 같은 흔들림이 오래 이어지면 증가가 느려진다는 가정).
  - 정차 중(속도 < 1km/h) `τ_rest = 15분` (휴식하면 줄어든다, CONCEPT 4장).
- 사람 기준 참고: ISO 2631-1 부록 D, 구토 발생 비율 MSI(%) ≈ K_m·MSDV, K_m ≈ 1/3 (성인 혼합 집단). 같은 MSDV에서 반려견은 프로필 민감도 S를 곱한다.
- 지수: `index = 100 · (1 − e^(−S·MSDV / M₀))`, `M₀ = 140`.
  - 보정 근거(가정): 보통 프로필(S=1)이 좌우 ±2.5m/s², 주기 6~7초 S자 고갯길을 30분 달리면 MSDV ≈ 75 → 지수 ≈ 41(주의). 고속도로 직선 정속은 거의 오르지 않는다.
- 단계: 낮음 < 40 ≤ 주의 < 70 ≤ 높음.

## 5. 프로필 민감도 S (곱)
| 요인 | 값 | 근거(가정) |
| --- | --- | --- |
| 체급 소형 / 중형 / 대형 | 1.2 / 1.0 / 0.9 | 작은 개가 같은 가속에 더 크게 흔들린다는 일반 관찰 |
| 나이 1살 미만 / 1~7살 / 8살 이상 | 1.3 / 1.0 / 1.1 | 어린 개는 전정기관이 덜 자라 차멀미가 흔하다는 수의학 일반 설명, 노령견은 가정 |
| 멀미 성향 낮음 / 보통 / 높음 | 0.7 / 1.0 / 1.5 | 보호자 응답(이력) |

## 6. 앞 구간 예보
- 경로 형상이 있으면 10초마다 앞 `FORECAST_MIN = 20분`(현재 속도 기준 거리)을 본다.
- **위험 구간**: 현재 속도로 갈 때 `v²·|κ| ≥ A_RISK = 1.0 m/s²`인 지점들. 300m보다 가까운 구간은 하나로 합친다. 시작 거리 = 현재 위치에서 첫 지점까지, 지속 시간 = 구간 길이 / v.
- **예상 지수·지속 시간**: 같은 필터·누적을 현재 상태에서 이어서 미리 돌려 구간 끝의 지수를 낸다. 이때 "안내 없이" 운전자는 지금 속도로 가되 굽이마다 횡가속 `A_DRIVER_MAX = 3.0 m/s²`(가정) 이하로 감속한다고 본다 — 고속도로 100km/h 그대로 고갯길을 달린다고 보면 예상이 터무니없이 커진다(에뮬레이터 확인 2026-10-29).
- **권장 속도**: 구간 최대 곡률 κ_max에서 `v_rec = √(A_COMFORT / κ_max)`, `A_COMFORT = 1.0 m/s²`. 안내 문구는 템플릿: "3km 뒤 굽은 길 8분, 콩이 멀미 주의 — 조금 일찍 감속해 주세요".
- 같은 구간 예보는 10분 쿨다운(F1-10).

## 7. 한계와 정직한 표기
- 반려견 대상 검증이 없다. 지수는 상대 비교(안내 전후, 프로필 간)에 쓰고 절대값을 의학적으로 해석하지 않는다.
- 1Hz 신호로는 0.5Hz 이상을 볼 수 없다.
- 경로 형상은 SDK가 주지 않아 시연 GPX에 기댄다(sdk_check.md). 실차에서는 방위 변화로 현재 횡가속만 잰다.
