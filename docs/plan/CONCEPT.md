# 같이가개 — 반려견과 차로 가는 모든 순간 (기획 v1, 쉼표에서 전환)

> 가칭. 이름은 바꿀 수 있다. 이 문서가 기능 범위의 최우선 기준이며, 이전 쉼표 문서(README·architecture·todo 등)와 충돌하면 이 문서를 따른다.
>
> **2026-10-31 재정비 (사용자 결정).** 엔진 0~100 값은 **주행 자극**(차량 흔들림 누적, 예전 이름 멀미 지수)이고 반려견 측정이 아니다. 반려견 상태는 **콩이 관찰 상태**(보호자 음성 신고만)로 따로 둔다. 길 안내는 Pleos 기본 내비가 맡고 같이가개는 주행 중 분할 창에서 NaviHelper 값만 보여 준다. 상태·문구 기준은 [../states.md](../states.md)·[../wording.md](../wording.md)이고, 아래 표현도 그에 맞췄다.

## 1. 한 줄
차량 흔들림(주행 자극)·이동 시간·배변 간격·운전자 피로로 쉬는 순간과 장소를 정해 주고, 잠깐 차에 남겨 둘 때부터 내릴 때까지 반려견의 이동 하루를 차가 함께 챙긴다.

## 2. 왜 (공감·차별점)
- 반려견은 아파도 말을 못 한다. 차멀미(침 흘림·헐떡임·구토)와 이동 불안이 흔한데, 운전자는 앞만 봐야 해서 알아채기 어렵다.
- 반려견 동반 여행 수요는 크지만, 차 안에서 쓰는 전용 서비스는 없다. 2026 Pleos 아이디어 공모전 우수작 16개에도 반려동물 주제는 없다.
- 해외 참고: Tesla Dog Mode(정차 중 반려견 대기 화면), JLR의 주행 데이터 기반 멀미 예측(사람 대상), Apple Vehicle Motion Cues.

## 3. 핵심 기능 (발표 순서)

## 4. 주행 자극 예보 엔진 (기술 활용성의 중심)
- 입력: 1초 단위 속도 v, 경로 앞쪽 형상(곡률 κ, NaviHelper 경로 좌표가 없으면 시연 경로 GPX), 정체 정보(있으면).
- 가속도: 종방향 a_x = Δv/Δt(잡음 처리 후), 횡방향 a_y = v²·κ.
- 누적량: ISO 2631-1의 멀미 누적량(MSDV) 개념을 단순화해 0.1~0.5Hz 대역 가속도 제곱 적분 → 반려견 프로필 민감도(체급·나이·흔들림에 예민한 정도(보호자 응답) 3단계, 음성 신고 자동 보정)로 보정 → 0~100 주행 자극(낮음 < 40 ≤ 보통 < 70 ≤ 높음). 정차·휴식 시 감소. (구현은 대역 0.02~0.5Hz로 결정, [motion_model.md](motion_model.md))
- 예보: 앞으로 10~20분 구간을 현재 속도로 가정해 미리 적분 → 굽은 길 시작 거리·지속 시간.
- 정직한 표현: 차량 흔들림 기준이며 반려견 측정·진단이 아니다. 숫자는 정차 중 "주행 자극 보기"·도착 후 리포트·발표 비교에서만. 계수는 문헌 기반 가정값이며 문서에 근거 표기.
- 시연 비교: 같은 고갯길(예: 미시령·대관령 옛길 형상)을 "안내 없이" vs "안내대로"로 시뮬레이션해 차이를 보여준다(실제 결과: 주행 자극 −45% (55 → 30), [demo_compare.md](demo_compare.md)).

## 5. 주행 중 규칙 (그대로 유지)
텍스트 2줄 이하, 버튼 2개 + 음성 힌트, 스크롤·자동 애니메이션 없음, CarUxRestrictions 준수. 대기 모드 화면은 P단에서만.

## 7. 시연 3분 흐름
1. 출발 체크(콩이 프로필, 하네스 체크) → 이대로 출발 (VHAL D단·속도)
2. 고속도로 주행 → 반려견 맞춤 쉼표 추천 → 음성 "여기서 쉴게요"
3. 휴게소 P단 → "잠깐 다녀올게" → 차 화면 대기 안내 + 폰 웹페이지 실시간
4. 고갯길 → 주행 자극 예보 "3km 뒤 굽은 길" 한 줄 → 정차 후 안내 없이/있이 비교 그래프
5. 도착 → "콩이 내렸나요?" → 도착 후 기록 리포트
