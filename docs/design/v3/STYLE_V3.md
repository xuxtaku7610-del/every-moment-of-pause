# 스타일 v3 — 깔끔하고 친근하게 (UI_SPEC v2를 덮어쓰는 부분)

기준 시안: `v3/v3-drive.png`, `v3/v3-pause.png` (원본 `v3/v3.html`). 이 두 화면이 최우선 기준이고, 나머지 15개 화면은 아래 규칙으로 v2 레이아웃을 다시 칠한다.

## 왜 바꾸나
- v2는 회색 바탕 + 회색 카드 + 글자뿐이라 허전하고, 차량 앱 같지 않고, 기능의 가치가 안 보였다.
- v3는 세 가지를 바꾼다: ① 고속도로 표지판처럼 생긴 큰 카드로 "차 안"이라는 느낌 ② 사람마다 색이 있는 친근한 아이콘 타일 ③ **기능의 가치를 그림으로**: "여기서 한 번에 해결돼요"(한 번 멈춰 네 가지 해결), "모두의 27분"(충전 시간에 가족 활동이 어떻게 들어가는지 타임라인).

## 토큰 (UI_SPEC §2.1 교체)
| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `bg` | `#FFFFFF` | 앱 배경(이제 흰색) |
| `grey` | `#F2F4F6` | 카드, 보조 버튼, 타일 |
| `grey2` | `#E5E8EB` | 비활성 링, 구분선 |
| `ink` / `ink2` / `ink3` | `#191F28` / `#4E5968` / `#8B95A1` | 글자 |
| `rest` / `restDark` / `restLight` | `#0B8A74` / `#08705E` / `#E3F5F0` | 브랜드, 표지판 카드, 주 버튼 |
| `kid` / `kidLight` | `#3182F6` / `#E8F3FF` | 아이 관련 |
| `pet` / `petLight` | `#FF8A3D` / `#FFF1E6` | 반려동물 관련 |
| `ev` / `evLight` | `#12B886` / `#E6F8F1` | 충전 관련 |
| `nap` / `napLight` | `#7C5CFC` / `#F0ECFF` | 운전자 휴식·파워냅 |
| `warn` / `warnLight` | `#F59F00` / `#FFF6E0` | 피로 주의, 기상 알림, 출발 준비 |
| `alert` | `#E8590C` | 피로 위험 |
| `road` / `roadDone` | `#3B424B` / `#2A3037` | 경로 띠 |

**사람·대상별 색은 모든 화면에서 고정한다**(아이=파랑, 반려동물=주황, 충전=초록, 운전자 휴식=보라). 이것이 "친근함"의 핵심이다.

## 모양
- 큰 카드 모서리 44dp, 일반 카드 36dp, 타일 28dp, 아이콘 상자 20~26dp(둥근 사각형, 원 아님).
- 버튼: 높이 120~136dp, 모서리 32dp(알약형 아님). 주 버튼 `rest`, 보조 버튼 `grey` + `ink2` 글자.
- 그림자 없음. 흰 배경 위 `grey` 면으로만 구분.
- 글자: 제목 굵기 800, 자간 -0.04em. 큰 숫자는 그대로 크게.

## 핵심 컴포넌트 (새로 추가·교체)
| 컴포넌트 | 규칙 |
| --- | --- |
| `HighwaySignCard` | `rest` 배경, 안쪽 14dp 들여 4dp 흰색 35% 테두리(표지판 느낌). 위에서 아래로 "다음 쉼표" → 휴게소 이름(96sp) → 노선·방향 → 왼쪽 아래 분(150sp)+거리, 오른쪽 아래 진출 화살표 상자 |
| `SolveTiles` | "여기서 한 번에 해결돼요" + 타일 최대 4개(아이콘 상자 72dp + 제목 28sp + 한 줄 설명 22sp, 한 줄 고정). 타일은 플래너가 실제로 맞춘 니즈만 표시 |
| `FatigueRing` | 지름 200dp, 두께 22dp, 0~100. 색은 단계별(편안 `ev`, 주의 `warn`, 위험 `alert`). 오른쪽에 단계 글자 44sp + 근거 2줄 |
| `RoadStrip` | 높이 72dp 띠(`road`) + 중앙 흰 점선, 지나온 구간 `roadDone`, 위에서 본 차 아이콘(현재 위치), 쉼표 핀(64×84dp, 다음 쉼표 `rest` 채움, 이후 쉼표는 흰색+테두리) + 핀 오른쪽 라벨 |
| `ChargeRing` | 지름 300dp, 두께 30dp, `ev`. 가운데 % (96sp) + "목표 80%" |
| `FamilyTimeline` ("모두의 27분") | 행 = 사람별 활동(아이콘 상자 80dp + 이름 + 한 줄), 오른쪽 트랙에 활동 막대(사람 색, 안에 흰 글자). 위에 시간축(지금/10분/20분/끝). 기상 알림 위치에 `warn` 점선. 마지막 행 "출발 준비 2분" |

## 다른 화면에 적용하는 법
- **출발 준비**: 흰 배경. 멤버 타일에 사람 색 적용(아이 파랑, 반려견 주황). 오른쪽 "오늘의 쉼표" 계획 아래 `RoadStrip`. 주 버튼 120dp 사각 둥근.
- **제안 없음**: 표지판 카드 대신 `grey` 큰 카드 + 풍경 일러스트 + "지금은 편안해요". 아래 `RoadStrip`.
- **긴급**: 표지판 카드를 `alert` 배경으로("지금 쉬어야 해요", 가장 가까운 졸음쉼터, 거리). 타일 없음. 버튼은 `alert` 하나.
- **파워냅**: 어두운 예외 유지. 링 색만 `nap` 보라로.
- **여행 리포트**: 흰 배경, 문장 요약 + 사람 색 태그, `RoadStrip`으로 실제 쉼표 위치 표시.
- **온보딩·설정**: 흰 배경, 리스트 행은 `grey` 카드, 아이콘 상자에 사람·기능 색.
- **1/2·1/3 창**: 표지판 카드를 폭에 맞게 세로로(이름 64sp, 분 120sp). 타일은 1/2 창에서 2개, 1/3 창에서 숨김.

## 주행 중 규칙(그대로)
글자 블록 2줄 이하, 버튼 2개(+음성 힌트), 스크롤·자동 애니메이션 없음. 타일은 아이콘+두 단어 제목 수준으로 유지.
