# 스타일 v6 — 같이가개 (현재 기준)

2026-10-30 "전체 UI 전면 재설계" 지시를 반영한 기준. [v5](../v5/STYLE_V5.md)는 대체됨(이력만). 색·글자 크기는 재설계 지시 값이 v5보다 우선한다.
코드: `ui/theme/{Color,Type,Dimens}.kt`, 부품 `ui/components/Kit.kt`, 화면 `ui/screens/{ScreenFrame,DriveScreens,PetScreens}.kt`, 보호자·병원 페이지 `server/app/pages.py`.
전후 캡처: `artifacts/ui/v6/<화면>-before-after.png` (`python scripts/ui_capture.py <태그>` → `--pair before after`).

## 1. 원칙
- **차량용 HMI**: 운전자는 2초 안에 본다. 주행 중 텍스트 2줄·버튼 2개·스크롤 없음·자동 애니메이션 없음(DrivingRules·UxPolicy는 그대로).
- **한 화면 = 한 뼈대.** 주행 중 모든 상태(평소·예보·추천·이상·병원)는 "왼쪽 경로 보기 + 오른쪽 상태 패널" 같은 자리에 그린다. 바뀌는 것은 오른쪽 내용뿐.
- **카드를 겹쳐 쌓지 않는다.** 화면당 큰 패널 1~3개, 패널 안은 얇은 구분선으로 나눈다. 그림자 없음.
- **강조색은 의미로만 하나씩.** 파랑 = 주 행동·경로, 앰버 = 주의·위험 예보, 초록 = 편안·정상. 네이비는 깊은 강조(차트 선·인사이트 선·결과 띠).
- **수치는 레이블·단위와 함께.** `멀미 지수` → `51 / 100` → `편안해요`. 크기만 키우지 않는다.
- **실제 값만.** 예보 그래프는 엔진이 준 값(지금 지수·굽은 길 시작 분·지속 분·구간 끝 예상 지수)을 이어 그린다. 지어낸 곡선 모양 금지.
- **지도 타일 없음.** "지도" 자리는 앞 1km 경로 곡률로 그린 경로 일러스트(무채색 바탕 + 파란 경로선 + 내 차, 굽은 길이 1km 안이면 그 지점부터 앰버).

## 4. 간격·모양 (기준값 × 배율)

## 5. 틀과 창 폭
- 모든 화면 = 앱 바(로고 + "같이가개" 또는 화면 이름, 오른쪽에 목적지·남은 시간) + 본문.
- 창 폭 FULL ≥1500 · HALF ≥1000 · THIRD(그 아래): 배치만 바뀌고 글자 크기는 그대로. THIRD 주행은 패널 하나(지수·휴식·다음 쉼표·버튼).

## 7. 화면
1. **주행 기본** — 경로 보기 58% + 상태 패널 42%: 반려견(원형 사진 64·이름·단계 알약) / 멀미 지수 36 + 게이지 / 마지막 휴식 후 · 다음 쉼표까지(시간 수치, 장소·km) / **최근 30분 멀미(1분 엔진 값) + "다음 굽은 길 n km 앞"**(10/31, 빈자리 대신). 다음 쉼표 문장은 수치와 겹치므로 계획이 없을 때만 한 줄. 1/2 창은 경로 보기 36%.
2. **멀미 예보** — 경로 보기 45% 위에 경고 띠(① "3.2km 뒤 굽은 길 · 12분" ② "콩이 멀미 높음 예보" 또는 코칭) + 상태 패널 55%: 지금 지수 · 20분 뒤 예상 → 게이지 → "앞으로 20분 · 예상 최고 n · m분 뒤" → 20분 그래프 → 범례·"진단 아님". 문자열 제한(LIMIT_STRING_LENGTH)이면 코칭 대신 "콩이 멀미 높음 예보".
3. **이동 기록** — (도착 질문 띠) → 요약 패널(총 주행 시간 · 휴식 · 멀미 주의 · 최고 지수, 세로 구분선) + 인사이트 한 줄(네이비 선, 이번 여행 값 먼저) → 아래 세 칸: 추이 그래프 38% | 관찰 기록 28% | 동물병원 공유용 요약 34%. "기록 확인"은 앱 바 오른쪽. 한 화면에 들어간다. 1/2 창은 그래프 | 관찰·요약(스크롤), 1/3 창은 수치 2×2 + 관찰·요약.
4. **반려견 상태** — 주행 상태 패널(1번)이 반려견 상태 부품이다. 프로필 화면은 왼쪽 원형 사진 140·이름·요약·맞춤 정도 + 오른쪽 편집.
5. **쉼표 추천** — 상태 패널 자리에: "쉼표 추천" 레이블 → 장소 24 + 방향 → 도착까지·거리 수치 → 이유 2개(체크) → 버튼 2개 + 음성 힌트.
6. **콩이가 이상해요** — 상태 패널 자리에: 경고 띠("반려견 안내" + 2줄) → 정차 장소 이름 24 + 약 n분 → 버튼 2개 → 하단 고정 "일반 안내예요…".
7. **병원 가는 길** — 상태 패널 자리에: 병원 이름 24 · 도착까지 분 · 거리 · 사전 접수 상태 알약(병원 응답).
8. **출발 체크** — 반려견 28% · 체크 38%(구분선 목록, n/3) · 경로 34%(예상 시간·쉼표 수 → 쉼표 목록 → 출발 버튼).
9. **쉼표(정차)** — 왼쪽(지금 상태·쉬는 시간·행동 버튼 세로) · 오른쪽(돌보기 체크리스트 → 지금 하면 좋은 것(구분선 목록) → 콩이가 이상해요 고르기).
10. **잠깐 대기** — 바깥 사람이 읽는 큰 글(제목 36·경과 시간 36) 62% · 차 안 상태(설정 시간·실내 온도·배터리) + 제한 시간·돌아왔어요 38%.
11. **함께 가는 장소** — 필터 줄 + 목록 한 패널(사진 3:2 고정 비율 120, 구분선).
12. **동물병원** — 목록 55% + 사전 접수 45%(증상 고르기·메모·포함 체크·접수 버튼 → 보낸 뒤 도착 예정·병원 응답·접수함 링크).
13. **도착 체크** — 한 패널 가운데: 원형 사진 180 + "콩이 내렸나요?" 36 + (덥거나 여름이면 경고 띠) + 내렸어요.
14. **설정·온보딩** — 2열 패널, 섹션 머리 + 구분선.

## 8. 보호자·병원 페이지 (`pages.py`)
앱과 같은 v6 색, 모서리 14, 경고 띠는 왼쪽 앰버 선. 표 줄은 이름을 줄바꿈하지 않고(`nowrap`) 값만 오른쪽에서 줄바꿈(`keep-all`).

## 9. 검수 방법
`python scripts/ui_capture.py --split half|third <태그> [화면]`(실제 분할 창, am task resize), `--dark`(cmd uimode night). 모아 보기 `artifacts/ui/v6/sheet-{half,third,dark}.png`.

`python scripts/ui_capture.py <태그>` — 주행·예보·쉼표·대기·도착은 시뮬레이터 실제 값(장면 점프), 이동 기록은 고갯길 앞부터 10배속으로 실제로 달린 기록, 나머지는 Fixtures 장면. `--pair before after`로 앱 영역만 잘라 나란히(Chrome 헤드리스).
