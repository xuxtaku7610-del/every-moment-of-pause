# 문구표: 옛 표현 → 새 표현 (2026-10-31 재정비)

원칙 ([states.md](states.md)): 엔진 0~100 값은 **주행 자극**(차량 흔들림 누적, ISO 2631-1 단순화)이다. 반려견 몸을 잰 값이 아니다.
반려견 상태는 **관찰 상태**(보호자 음성 신고만)로 말하고, 두 값을 섞지 않는다. 진단·확률·"멀미 측정" 표현은 쓰지 않는다.
코드 안 이름(`MotionComfortEngine`, `motionPeak`, `MotionTone` 등)은 그대로 두고 화면·음성·문서 표현만 바꾼다.
접수 양식·발표 자료도 이 표를 따른다.

## 쓰지 않는 말
