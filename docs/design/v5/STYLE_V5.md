# 스타일 v5 — 같이가개 (현재 기준)

기준: [`overview.png`](overview.png)(1536×1024, 12개 화면 + 디자인 토큰 표) + [`DESIGNER_NOTES.md`](DESIGNER_NOTES.md). 색·글자는 디자이너 메모 값이 우선이고 이미지는 확인용이다. [`overview_a.png`](overview_a.png)는 이전 안(참고만). v2(UI_SPEC)·v3·v4는 폐기.

화면별로 자른 그림: `screens/01-depart.png` … `12-icon.png`, `13-tokens.png` (PIL 일회성 자르기, 좌표는 §6 표).

## 0. 단위 — 디자인 기준값 × 배율
디자이너 메모의 크기(Body 16sp, 여백 24dp …)는 1920×1080 프레임을 1280×720dp(1.5x)로 본 **기준값**이다. 대상 에뮬레이터 `Pleos_Connect_API34`는 2560×1440px·160dpi = **2560×1440dp**라서 기준값을 **2배**로 쓴다.

- 배율 `scale = 화면 폭(dp) / 1280`, 1~2로 제한. 화면 전체 폭(`screenWidthDp`)으로 정하므로 **분할 창에서도 글자 크기는 그대로**(창이 좁아지면 배치만 바뀐다, §5).
- 아래 표는 기준값과 2560dp 화면 값을 함께 적는다. 코드는 기준값 × `scale` (`V5Dimens`, `V5Type`).
- 시안 그림의 가로 1px ≈ 1920/패널폭 배로 비율만 읽었다(시안 해상도가 낮다).
