# 시연 비교 — 고갯길 "안내 없이" vs "안내대로" (F1-07)

실행: `cd app-android` → `./gradlew :app:testDebugUnitTest --tests "*DemoCompareTest*"` → `app/build/demo_compare/`에 CSV·요약이 생긴다. 숫자는 모두 **주행 자극**(차량 흔들림 누적, 예전 이름 멀미 지수)이다. 발표 모드 비교 화면은 "주행 자극 −45% (55 → 30)"로 보인다. 이 문서의 표와 [demo_compare.csv](demo_compare.csv)(시연 반려견), [demo_compare_normal.csv](demo_compare_normal.csv)(보통 반려견)는 2026-10-29 실행 결과다.

### 이전 결과와의 차이
- 합성 형상(12.2km, 2026-10-29 오전)에서는 37 → 26(−30%, 3분 더)이었다. 실제 도로는 더 길고 헤어핀이 많아 "안내 없이"의 누적이 크고, 안내대로의 감속 이득도 크다. 승인받은 37 → 26은 **합성 형상 기준 값**이고, 지금 시연 숫자는 위 표(55 → 30)다.

## 읽는 법·한계 (발표 때 그대로 말한다)
- 주행 자극은 **차량 흔들림 기준**이고 반려견 측정·의학적 진단이 아니다. ISO 2631-1 멀미 누적량(MSDV)을 단순화했고 계수는 가정값이며 반려견 대상 검증은 없다. 비교는 **같은 모델 안에서의 상대 차이**로만 말한다.
- CONCEPT 4장의 "82 → 41"은 예시였다. 이 모델·이 도로에서는 고갯길만 놓고 55 → 30이다. 실제 시연 시나리오(`pet-trip`)에서는 고속도로 2시간 반의 누적과 휴게소 회복이 앞에 붙어 숫자가 달라진다.
- OSM 선형은 실제 도로 중심선이지만 꼭짓점 간격이 고르지 않다. 곡률은 30m 창(앞뒤 30m 세 점의 외접원)으로 고르게 펴서 쓴다 (`RouteShape`).
- 안내대로는 7분 더 걸린다. "조금 늦게, 덜 흔들리게"가 메시지다. 주행 중 안내는 숫자 없이 한 줄("천천히 가면 덜 흔들려요")이고, 이 비교 숫자는 정차 중 발표 모드에서만 보인다.
- 개인 보정 시드를 넣은 뒤에는 같은 길의 최고값이 바뀐다(55 → 72, [../demo_numbers.md](../demo_numbers.md)). 비교는 보정 없는 프로필로 보인다.
- 실차에서는 이 GPX 대신 회전 안내·진행 방위로 앞 굽이를 추정한다 — 두 구현 비교는 [shape_compare.md](shape_compare.md).
