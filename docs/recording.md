# 시연 영상 녹화 순서 — 같이가개

장면 순서·말할 것은 [demo_script.md](demo_script.md), 자동 리허설은 `python scripts/rehearsal.py`. 영상은 **3분 이내**.
녹화 전 준비는 demo_script.md "준비"와 같다(DB 적재, 서버 `--host 0.0.0.0`, 에뮬레이터, 디버그 앱, 보호자 폰 같은 Wi-Fi).

## 1. 녹화 방법 (2026-10-30 둘 다 동작 확인)

### A. `adb shell screenrecord` (권장 — 장면별로 끊어 찍기)
```powershell
# 한 파일 최대 180초. 2560×1440은 인코더 한계라 1920×1080으로 줄여 찍는다.
adb shell screenrecord --time-limit 60 --size 1920x1080 --bit-rate 12000000 /sdcard/scene1.mp4
adb pull /sdcard/scene1.mp4 artifacts/recording/
adb shell rm /sdcard/scene1.mp4
```
- 장면마다 한 파일 → 편집에서 잇는다(점프 대기 시간을 잘라낼 수 있다).
- 소리는 녹음되지 않는다 → TTS·내레이션은 따로(아래 3).

### B. 에뮬레이터 녹화 (webm, 한 번에 길게)
```powershell
adb emu screenrecord start --time-limit 180 C:\every-moment-of-pause\artifacts\recording\full.webm
# … 시연 …
adb emu screenrecord stop
```
또는 에뮬레이터 확장 컨트롤(…) → **Record and Playback** → Start recording. 이것도 소리는 없다.

### 앱 영역만 자르기 (선택)
Pleos 왼쪽 차량 패널·위아래 시스템 바를 빼고 싶으면(2560×1440 원본 기준 앱 영역 x 853–2535, y 90–1300):
```powershell
ffmpeg -i scene1.mp4 -vf "crop=iw*1682/2560:ih*1210/1440:iw*853/2560:ih*90/1440" scene1_app.mp4
```
차량 화면 안에서 동작하는 것을 보여 주는 것도 심사에 의미가 있으므로, 첫 장면은 전체 화면을 권장.

### 보호자 폰
실제 폰 화면 녹화(안드로이드: 빠른 설정 "화면 녹화", iOS: 제어 센터 "화면 기록") 또는 노트북에서 Playwright 390×844 캡처(`artifacts/ui/final_v5/06-phone-*`). 편집에서 대기 장면 옆에 나란히(PIP).

## 2. 장면별 길이와 자막 초안 (총 2:55)

| # | 장면 (발표 모드 패널 / adb) | 길이 | 화면에서 보일 것 | 자막 초안 |
| --- | --- | --- | --- | --- |
| 1 | 출발 체크 (`--ei seek 0`) | 0:00–0:20 (20초) | 반려견 사진·체크 3개 → "이대로 출발" 켜짐 | 반려견은 아파도 말을 못 합니다. 같이가개는 타기 전부터 챙깁니다. |
| 1b | 콩이가 이상해요 (`--ei seek 2400 --ei cabin 31` → `--es say '콩이가 헥헥거려'`) | (+30초) | 반려견 안내 2줄 + 여주휴게소로 / 괜찮아졌어요 + 하단 "일반 안내예요…" | 운전 중엔 돌아보지 말고 말로만. 실내 온도·계절을 같이 보고 가장 가까운 안전한 곳을 고릅니다. 진단이 아닌 일반 안내예요. |
| 2 | 고속도로 (`--ei seek 210`) | 0:20–0:30 (10초) | 콩이 · 편안해요, 멀미 지수, 다음 쉼표 약 72km, 원근 도로 | 주행 중에는 두 줄과 버튼 두 개만 보여요. |
| 3 | 쉼표 추천 (`--ei seek 3420`, 약 40초 대기 — **편집에서 30초 잘라냄**) | 0:30–0:50 (20초) | 횡성휴게소 · 32분 · 반려견 놀이터, 버튼 2개 → "경로에 추가했어요" | 멀미 누적·배변 간격·운전자 피로를 합쳐, 반려견 놀이터가 있는 휴게소 한 곳을 고릅니다. |
| 4 | 휴게소 쉼표 → 잠깐 대기 (`5240` → `5540`, `--es say '잠깐 다녀올게'`) | 0:50–1:25 (35초) | 쉼표 화면 → "주인이 곧 돌아와요" + 안전 안내 → 폰 페이지 PIP → 폰 "돌아가는 중" → 차 화면 "주인이 돌아오는 중이에요" | P단에서만 켜집니다. 차 화면은 바깥 사람용 안내판, 폰에는 경과 시간. 위치는 보내지 않아요. 반려견을 차에 오래 혼자 두지 마세요. |
| 5 | 고갯길 예보 (`8748`) | 1:25–1:55 (30초) | 경고 띠 "3.2km 뒤 굽은 길 · 12분" + 20분 그래프 | 속도·방위·앞 구간 굽이로 반려견이 받을 흔들림을 미리 계산합니다. 진단이 아닌 주의 예보입니다. |
| 6 | 고갯길 비교 (`--ez demo true`) | 1:55–2:10 (15초) | 패널 "멀미 지수 55 → 30 · 20분 → 27분" | 실제 대관령 옛길 15km(OpenStreetMap). 안내대로 가면 7분 더 걸리고 멀미 지수는 45% 낮아요. |
| 7 | 함께 가는 장소·동물병원 (정차 화면에서 버튼) | 2:10–2:30 (20초) | TourAPI 사진 목록 → 동물병원 "영업 중" · 도착 예정 공유 | 한국관광공사 반려동물 동반여행 117곳, 동물병원 인허가 5,063곳. 도착 예정은 링크로 보호자가 직접 전달해요. |
| 8 | 도착 체크 → 이동 기록 (`10843`) | 2:30–2:55 (25초) | "콩이 내렸나요?" → 내렸어요 → 이동 기록(한계 카드·그래프) | 시동을 끄면 한 번 더 묻습니다. 기록이 쌓이면 "콩이는 1시간 10분쯤이 한계"를 알려 줘요. |

- 마지막 화면 하단 고정 자막(5초): "멀미 지수는 의학적 진단이 아닌 주의 예보입니다 · 지도 © OpenStreetMap contributors (ODbL) · 장소 사진 한국관광공사".
- 1b(30초)를 넣으면 3분이 넘으므로 장면 7(장소·병원)을 뺀다 — demo_script.md 표와 같은 순서·길이(3:00).
- 고갯길 비교(장면 6)는 패널 "고갯길 비교 크게 보기" 전체 화면 그래프로(`--ez compare true`).

## 3. 소리
- 앱 TTS(제안·예보)는 화면 녹화에 들어가지 않는다. 노트북 스피커 출력을 함께 담으려면 OBS로 에뮬레이터 창 + 시스템 소리를 녹화하거나, 편집에서 내레이션을 입힌다.
- 내레이션은 자막 초안과 같은 문장으로, 장면 길이 안에 끝나게(1초에 약 4~5음절).

- [ ] 에뮬레이터 시간·알림 정리, 발표 모드 패널 닫기(장면 6 제외)
