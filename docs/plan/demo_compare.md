## 읽는 법·한계 (발표 때 그대로 말한다)
- 지수는 **주의 예보**이고 의학적 진단이 아니다. 계수는 문헌을 참고한 가정값이며 반려견 대상 검증은 없다. 비교는 **같은 모델 안에서의 상대 차이**로만 말한다.
- CONCEPT 4장의 "82 → 41"은 예시였다. 이 모델·이 형상에서는 고갯길만 놓고 37 → 26이다. 실제 시연 시나리오(`pet-trip`)에서는 고속도로 2시간 반의 누적과 휴게소 회복이 앞에 붙어 숫자가 달라진다.
- 경로 형상은 합성이다. 실제 고갯길의 곡률 분포와 다를 수 있다.
- 안내대로는 3분 더 걸린다. "조금 늦게, 덜 흔들리게"가 메시지다.
