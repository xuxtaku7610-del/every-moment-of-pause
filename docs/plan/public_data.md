# 공공데이터 적재 기준과 건수 (2026-10-30)

실행: `docker compose up -d db` → `cd server` → `.venv\Scripts\python -m app.jobs.ingest_pet_places` / `-m app.jobs.load_vets` / `-m app.jobs.ingest_reststops`.
키(`TOUR_API_KEY`)는 `server/.env`에서 환경 변수로만 읽고, 로그에는 어디서도 `serviceKey` 값이 남지 않는다(`app/logmask.py`, 테스트 `test_sv_08_*`).
