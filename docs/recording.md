# 시연 영상 녹화 순서 — 같이가개

장면 순서·말할 것은 [demo_script.md](demo_script.md), 자동 리허설은 `python scripts/rehearsal.py`. 영상은 **3분 이내**.
녹화 전 준비는 demo_script.md "준비"와 같다(DB 적재, 서버 `--host 0.0.0.0`, 에뮬레이터, 디버그 앱, 보호자 폰 같은 Wi-Fi).

**한 번에 점검 (11/02):** `powershell -ExecutionPolicy Bypass -File scripts\demo_check.ps1 -Prepare -ShareBase http://<노트북 IP>:8000` (주소를 모르면 `-DetectIp` — Wi-Fi IPv4를 찾아 넣고, 방화벽 8000 규칙이 없으면 관리자 명령만 보여 준다, 11/03) (점검만은 옵션 없이, 리허설까지는 `-Rehearsal`)
— `-Prepare`: 꺼진 DB·서버·에뮬레이터(남은 메모리 6GB 미만이면 켜지 않음)·앱(`-Install`이면 다시 설치)을 켜고 앱을 새로 띄움 → 점검 줄마다 OK/WARN/FAIL(Gradle 데몬·adb·부팅·앱 버전·PostgreSQL·서버·Ollama·남은 메모리) → `-Rehearsal`이면 아래 "기본 내비 안내 걸기" 안내(Enter) → 리허설 1회.
쉴 때는 `-Stop`(Gradle 데몬·서버·에뮬레이터·DB 정리). 에뮬레이터는 호스트 메모리를 5~6GB 쓰므로 녹화 전에 브라우저 탭과 Gradle 데몬(`.\gradlew --stop`)을 정리한다.

## 0. 자동 촬영 (2026-11-03) — `scripts/record_scenes.py`
```powershell
powershell -ExecutionPolicy Bypass -File scripts\demo_check.ps1 -Prepare -DetectIp     # 폰 QR 주소(-ShareBase)를 Wi-Fi IPv4로
server\.venv\Scripts\python scripts/record_scenes.py --share-base http://<노트북 IP>:8000   # v10 10장면, 장면마다 mp4 + 폰 PIP 3개
```
- 순서 (v10, 11/05): 출발 전 → 기본 내비 전체 화면·뒤에서 예보 → 분할 창·눌러서 말하기 → 배변 임박 쉼표 → 휴게소 문·잠깐 대기(+ 보호자 폰) → 콩이 도우미 → 주행 중 초콜릿 → 병원 사전 접수(+ 접수함) → 흔들림 그래프·고갯길 비교 → 주변 추천 → 뒷문·도착 요약·폰으로 기록 받기(+ 기록 페이지). 녹화 전 앱을 새로 띄우고(force-stop) `captureClean`으로 "시연 데이터" 표시를 숨긴다.
- 결과: `artifacts/recording/<날짜>/NN-<장면>.mp4`(1920×1080, 소리 없음, 편집 없음) + `index.md`(장면·길이·비고). 폰 PIP 3개(보호자 대기 페이지·병원 접수함·기록 페이지)는 모두 390×844 — Playwright가 있으면 webm, 없으면 Chrome 헤드리스 1초 간격 PNG 묶음. Playwright는 `server/.venv`에 설치되어 있다(11/03) — 웹도 영상으로 찍으려면 `server\.venv\Scripts\python scripts/record_scenes.py`로 실행(시스템 python이면 PNG 묶음).
- 시작 전 확인: adb 기기, 서버, **기본 내비 안내 중인지**(내비 화면에 "안내 종료"). 안내 중이 아니면 아래 "기본 내비 안내 걸기"를 안내하고 Enter를 기다린다. `--no-wait`이면 멈추지 않고 분할 창 장면을 전체 창으로 찍는다. 일부만: `--only 7,8`.

## 1. 녹화 방법 (2026-10-30 둘 다 동작 확인)

### A. `adb shell screenrecord` (권장 — 장면별로 끊어 찍기)
```powershell
# 한 파일 최대 180초. 2560×1440은 인코더 한계라 1920×1080으로 줄여 찍는다.
adb shell screenrecord --time-limit 60 --size 1920x1080 --bit-rate 12000000 /sdcard/scene1.mp4
adb pull /sdcard/scene1.mp4 artifacts/recording/
adb shell rm /sdcard/scene1.mp4
```
- 장면마다 한 파일 → 편집에서 잇는다(점프 대기 시간을 잘라낼 수 있다).
- 소리는 녹음되지 않는다 → TTS·내레이션은 따로(아래 3).

### B. 에뮬레이터 녹화 (webm, 한 번에 길게)
```powershell
adb emu screenrecord start --time-limit 180 C:\every-moment-of-pause\artifacts\recording\full.webm
# … 시연 …
adb emu screenrecord stop
```
또는 에뮬레이터 확장 컨트롤(…) → **Record and Playback** → Start recording. 이것도 소리는 없다.

### 앱 영역만 자르기 (선택)
Pleos 왼쪽 차량 패널·위아래 시스템 바를 빼고 싶으면(2560×1440 원본 기준 앱 영역 x 853–2535, y 90–1300):
```powershell
ffmpeg -i scene1.mp4 -vf "crop=iw*1682/2560:ih*1210/1440:iw*853/2560:ih*90/1440" scene1_app.mp4
```
차량 화면 안에서 동작하는 것을 보여 주는 것도 심사에 의미가 있으므로, 첫 장면은 전체 화면을 권장.

### 기본 내비 안내 걸기 (주행 장면 전에, 11/01 확인)
다음 회전 카드는 NaviHelper `onTBTInfo` 실제 값이다. 기본 내비가 안내 중이 아니면 카드 대신 "목적지 · 남은 거리 · 도착" 한 줄만 보인다. 녹화 전에:
1. 런처 아래 내비 아이콘(또는 `adb shell monkey -p ai.umos.maps.android.navigation.app -c android.intent.category.LAUNCHER 1`)으로 기본 내비를 연다.
2. "어디로 갈까요?" → 최근 목록의 **강릉씨티호텔** 오른쪽 화살표(바로 안내). 처음이면 검색창에 "강릉"을 쳐서 고른 뒤 "안내 시작". 아래 카드에 "2시간 9분 · 194km"와 "안내 종료"가 보이면 안내 중이다. (`geo:` 인텐트는 목적지만 열고 안내를 걸지 않는다 — BLOCKED 10/30)
3. 같이가개를 앞으로 → 장면 점프 → 분할(아래). 시뮬레이터 모드에서도 회전 안내만 기본 내비 값을 받는다(`SignalRuntime.simGuide`, 10초마다 조회). 에뮬레이터 내비는 위치가 움직이지 않아 "좌회전 80m · 기업지원허브 방면"으로 고정이다 — 시뮬레이터의 남은 거리·도착과는 따로다(실차에서는 둘 다 같은 내비 값).
4. 끝나면 내비에서 "안내 종료".

캡처: `python scripts/ui_capture.py --out v8 --nav nav 01-drive 02-forecast 07-distress`. 쉼표 추천(3420초)은 분할에 10초가 걸려 장면이 지나가므로 1/3 창(`--split third`)으로 찍는다. 대기·도착 예정 링크 QR은 `--es shareBase http://(노트북 Wi-Fi 주소):8000`을 먼저 넣어야 전체 주소(QR)가 된다. 발표 직전에는 앱을 새로 띄운다(`adb shell am force-stop com.emop.pause`). 장면 점프 뒤 "듣고 있어요" 멈춤은 11/02에 고쳤다(BLOCKED 11/01) — 새로 띄우는 것은 깨끗한 상태에서 시작하려는 것.

### 분할 창 (주행 장면)
주행 장면은 기본 내비 옆 분할 창으로 찍는다. 장면을 띄운 뒤 앱 영역 오른쪽 끝 손잡이를 끈다: `adb shell input swipe 2547 720 1700 720 800` → 같이가개(왼쪽) + 기본 내비(오른쪽). 정차 장면(비교·리포트)은 전체 창으로 되돌려 찍는다. 이때는 앱 영역만 자르지 말고 전체 화면으로 찍어야 기본 내비가 함께 보인다.

### 보호자 폰
실제 폰 화면 녹화(안드로이드: 빠른 설정 "화면 녹화", iOS: 제어 센터 "화면 기록") 또는 노트북에서 Playwright 390×844 캡처(`artifacts/ui/final_v5/06-phone-*`). 편집에서 대기 장면 옆에 나란히(PIP).

- 분할 창 장면(3·4·9)은 기본 내비가 **안내 중**이어야 한다(아래 recording.md "기본 내비 안내 걸기"). 7(주행 중 응급)은 전체 창 — [동물병원으로]가 기본 내비 목적지를 병원으로 바꿔 안내가 끝나므로 녹화 스크립트는 9 뒤에 찍는다(파일 번호는 영상 순서). 정차 장면(5·6·8·10)은 전체 창.

## 3. 소리
- 앱 TTS(제안·예보)는 화면 녹화에 들어가지 않는다. 노트북 스피커 출력을 함께 담으려면 OBS로 에뮬레이터 창 + 시스템 소리를 녹화하거나, 편집에서 내레이션을 입힌다.
- 내레이션은 자막 초안과 같은 문장으로, 장면 길이 안에 끝나게(1초에 약 4~5음절).
