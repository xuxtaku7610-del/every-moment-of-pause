# 3분 시연 대본 — 같이가개 (PT 핵심 3장면)

준비: 노트북에서 DB(`docker compose up -d db`, 휴게소·장소·병원 적재 — [docs/plan/public_data.md](plan/public_data.md))·서버(`uvicorn ... --host 0.0.0.0`)·에뮬레이터(`Pleos_Connect_API34`)·앱(디버그) 실행, 보호자 역할 폰은 같은 Wi-Fi. 앱은 `--es sim pet-trip`으로 열고 `--es shareBase http://<노트북 IP>:8000`을 한 번 넣어 둔다. 자세한 순서는 아래 "보호자 폰 대기 페이지 준비".
장면 이동은 발표 모드 패널(로고 5번 탭 → "장면으로 이동") 또는 `scripts/vhal.ps1 <장면>`. 각 장면 시각은 `DemoScenes.kt`.

## 보호자 폰 대기 페이지 준비 (같은 Wi-Fi)
폰은 에뮬레이터 주소 `10.0.2.2`로 노트북에 닿지 못한다. 노트북의 Wi-Fi IP로 서버를 열고, 그 주소를 앱에 알려 준다.

1. **노트북과 폰을 같은 Wi-Fi에 연결**한다. 게스트·공용 Wi-Fi는 기기끼리 통신을 막는 경우가 많다 → 막히면 폰 핫스팟에 노트북을 붙인다.
2. **노트북 IP 찾기** (PowerShell):
   ```powershell
   Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.InterfaceAlias -match 'Wi-?Fi' } | Select-Object InterfaceAlias, IPAddress
   ```
   또는 `ipconfig | findstr IPv4` → "무선 LAN 어댑터 Wi-Fi"의 `IPv4 주소`(예: `192.168.0.23`). 아래에서 `<IP>`로 쓴다.
3. **서버를 모든 주소로 열기**:
   ```powershell
   docker compose up -d db
   cd server
   .venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
4. **방화벽 허용**: 처음 실행하면 Windows 보안 경고 창이 뜬다 → "개인 네트워크" 허용. 창이 안 떴는데 폰에서 안 열리면(관리자 PowerShell, 시스템 설정 변경이므로 직접 실행):
   ```powershell
   New-NetFirewallRule -DisplayName "gatigage-demo-8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
   ```
   시연이 끝나면 `Remove-NetFirewallRule -DisplayName "gatigage-demo-8000"`.
5. **폰에서 먼저 확인**: 폰 브라우저로 `http://<IP>:8000/api/v1/health` → JSON 응답(`"status"` 등)이 보이면 연결된 것이다.
6. **앱에 주소 알려 주기** (에뮬레이터, 한 번만):
   ```powershell
   adb shell am start -n com.emop.pause/.MainActivity --es shareBase http://<IP>:8000
   ```
7. **대기 모드 시작**: 휴게소 쉼표 장면에서 "잠깐 다녀올게" → 차 화면 아래에 `http://<IP>:8000/wait/<토큰>`이 보인다. 그 주소를 폰 브라우저에 입력한다. 토큰은 대기를 시작할 때마다 새로 생기므로 북마크하지 말고 매번 화면의 주소를 쓴다.
8. 폰 페이지는 5초마다 경과 시간·실내 온도·배터리를 갱신하고, 제한 시간을 넘으면 빨간 "시간 초과"로 바뀐다. 위치는 보내지 않는다. 대기를 끝내거나 주행을 시작하면 페이지는 "끝난 대기"가 된다(토큰 2시간 만료).

안 될 때: ① 폰에서 5번이 안 열리면 Wi-Fi·방화벽 문제 ② 5번은 되는데 대기 화면에 "폰 공유 연결 안 됨"이면 에뮬레이터 앱 → 서버(`10.0.2.2:8000`) 연결 문제(서버가 켜져 있는지) ③ 주소가 `/wait/...`로만 보이면 6번을 다시 한다.

## 예비 (실패할 때)
- 서버가 죽으면: 휴게소·장소·병원은 앱 내장 샘플, 문장은 템플릿으로 그대로 돈다. 폰 공유만 "연결 안 됨" → 차 화면 대기 안내만 보여 준다.
- 음성 인식이 안 되면: 화면 버튼("여기서 쉴게요")이나 패널 "운전자 응답 넣기".
- 장면이 꼬이면: 패널에서 해당 장면 버튼을 다시 누른다(점프하면 엔진이 그 시각까지 조용히 따라잡는다).
- 화면 자체가 문제면: 패널 "장면 고정"으로 고정 장면(`Fixtures`)을 보여 준다.
