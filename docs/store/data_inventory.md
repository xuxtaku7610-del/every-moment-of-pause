# 데이터 처리 표 (2026-11-02, 코드 기준)

개인정보 처리방침([privacy.md](privacy.md))의 근거 표다. 값은 모두 코드에서 확인했다(파일:줄은 2026-11-02 작업 트리 기준).
경로 약어: **A** = `app-android/app/src/main/kotlin/com/emop/pause/`, **S** = `server/app/`.

## 먼저 알아 둘 두 가지
1. **제출본(릴리스 1.0.0)은 우리 서버에 연결하지 않는다.** 릴리스 빌드는 `SERVER_BASE_URL = ""`(`app-android/app/build.gradle.kts` release 블록)이고, 주소가 비면 서버 객체가 만들어지지 않는다(`A/di/DataModule.kt`).
   - 그래서 아래 표에서 **"서버"라고 적힌 줄은 서버를 켠 빌드(지금은 시연용 디버그 빌드 + 노트북 서버)에만** 해당한다.
   - 실제 출시 때 클라우드 서버를 붙이면 그 줄들이 살아난다.
2. **위치 권한이 없다.** 매니페스트에 `ACCESS_FINE/COARSE_LOCATION`이 없고, `LocationManager`·Fused Location도 쓰지 않는다.
   - 현재 위치는 Pleos 기본 내비(NaviHelper `onCurrentLocationInfo`)가 알려 주는 값을 **메모리에서만** 쓴다.
   - 기기·서버 어디에도 이용자 좌표를 저장하지 않는다. 좌표가 저장되는 곳은 공공데이터(휴게소·장소·병원)뿐이다.

## 불일치 (코드와 기존 문서·화면 문구가 다른 곳)
코드는 바꾸지 않았다(11/8 동결 전 화면 변경 금지). 고칠지는 사용자 결정.

1. **반려견 이름이 서버로 간다.** `database.md:3` "개인 데이터는 서버로 보내지 않는다", `architecture.md:232` "반려견 프로필 … 서버 전송 안 함", 앱 설정 문구 "반려견 프로필·이동 기록은 이 차에만 있어요"(`PetScreens.kt:778`)와 다르다.
   - 실제: 도착 예정 공유·병원 사전 접수 때 `petName`(`MainViewModel.kt:526`), 메모 원문·증상·오늘 요약 한 줄이 서버 `eta_shares`에 2시간(+정리 1일) 저장된다.
2. **"함께 보내기"가 자동으로 켜진다.** `api_spec.md:242` "`symptoms`·`memo`·`tripLine`은 사용자가 체크했을 때만"과 다르다.
   - 실제: 주행 중 신고를 받아들이면 `include = true`가 된다(`MainViewModel.kt:707`). 그 뒤 음성 질문은 "증상과 도착 예정을 보낼까요?"라서 반려견 이름·메모·오늘 요약이 함께 간다는 말이 없다(README F5, architecture:237 "주행 중 음성 '네'").
3. **주행 중 음성 신고가 마이크와 이어져 있지 않다.** README F9·states.md 상태 5와 주행 화면 힌트("콩이 토했어"처럼 말하면 기록해요)는 말로 신고한다고 한다.
   - 실제: `PetDistress.classify`는 `TripCoordinator.reply()`에서만 불린다. `reply()`에 들어오는 길은 디버그 adb `--es say`와 발표 모드 패널뿐이다. 마이크 인식(ReplyGate)은 응/나중에만 본다. 실차에서는 정차 중 증상 고르기로만 신고된다.

6. **database.md §3 기기 DB 설명이 코드와 다르다.**
