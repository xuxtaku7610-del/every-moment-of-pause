# 스타일 v10 — 같이가개 (현재 기준, 2026-11-04)

[v6](../v6/STYLE_V6.md)의 색·간격 토큰은 그대로 쓰고, **글자 위계·영역 구분·화면 비율·그래프**를 다시 정한다. v6 §3(글자)·§6(부품)·§7(화면)은 이 문서로 대체.
지시: `_private/V10_2_UI.md`(사용자가 짚은 문제 4가지가 해결 기준). 기능·흐름은 바꾸지 않는다 — 배치·글자·구분만.
코드: `ui/theme/Type.kt`(글자 4단계), `ui/components/Kit.kt`(부품), 화면 `ui/screens/*`. 전후 캡처 `artifacts/ui/v10/`.

## 0. 해결 기준 (사용자가 짚은 문제)
| # | 문제 | v10 규칙 |
| --- | --- | --- |
| 1 | 이미지가 좁고 길게 놓이거나 중요하지 않은 영역이 화면을 잡아먹는다 | 화면별 영역 비율을 숫자로(§4). 사진·그림은 정해진 비율만, 장식 그림은 화면당 1개 |
| 2 | 글자 크기·위계가 제각각, 배너는 크고 데이터는 작다 | 글자 4단계만(§1). 경고 띠 문구 ≤ 제목. 화면마다 "가장 중요한 한 가지" = 수치 또는 제목 |
| 3 | 모든 정보를 둥근 박스에 넣는다 | 여백 → 구분선 → 배경 명도 → 카드 순(§2). 화면당 카드 최대 2장, 테두리·그림자 없음 |
| 4 | 흔들림 그래프가 넓은데 정보가 적다 | 시간 축·0~100 축·단계 띠, 지나온 실선·예측 점선, 수치 3개, 그래프 높이 ≤ 40%(§5) |

## 1. 글자 — 4단계만 (Pretendard, 기준값 sp × 배율, 2560 화면 배율 2)
| 단계 | 토큰 | 크기/줄 | 굵기 | 색 | 쓰는 곳 |
| --- | --- | --- | --- | --- | --- |
| **제목** | `Pause.type.title` / `Title()` | 24/32 | SemiBold | text | 화면·카드 제목, 장소·병원 이름, 경고 띠 첫 줄(이보다 크게 쓰지 않는다) |
| **수치** | `Pause.type.metric` / `Metric()` | 36/44 | Bold | text (의미가 있을 때만 warningInk·primary) | 가장 중요한 숫자 한두 개 + 단위. 단위는 설명 크기·sub |
| **설명** | `Pause.type.body` / `Body()` | 16/24 | Medium | text (신고 등 의미 있는 줄만 warningInk) | 본문, 값 한 줄, 목록 줄, 버튼 글자(버튼은 SemiBold) |
| **보조** | `Pause.type.caption` / `Caption()` | 14/20 | Regular | sub | 레이블("다음 쉼표"), 출처, 힌트, 그래프 축, 고정 문구 |
- 다른 크기·굵기는 쓰지 않는다. v6의 `metricSmall`·`h1`·`section`·`bodyStrong`·`sub`·`metricLabel`·`caption 12`·v5 별칭(`display`·`number`·`h2`·`label`)은 **지웠다**(컴파일이 막는다).
- 강조는 크기를 키우지 않고 **단계를 올린다**(설명 → 제목 → 수치). 한 영역에 수치는 최대 3개.
- **주행 중 최소 크기 = 설명(16 × 배율 = 2560 화면 32sp)**. 주행 화면의 보조는 레이블(한두 단어)에만.
- 숫자는 고정폭(tnum). 줄임표 대신 2줄 허용(버튼 글자는 자르지 않는다 — 10/31 규칙 유지).

## 2. 영역 나누기 — 우선순위
1. **여백**: 영역 사이 16(gap)·24(margin), 같은 영역 안 줄 사이 8~12. 먼저 여백으로 묶음을 보이게 한다.
2. **얇은 구분선**(`Divider`, 1): 같은 면 안에서 항목·묶음 사이.
3. **배경 명도**(`Block(tone = …)`): 바탕(bg) 위 면(surface), 면 안의 한 칸(surfaceAlt), 상태 면(primarySoft·warningSoft). 테두리 없음.
4. **카드**(`Block`): 꼭 필요할 때만, **화면당 최대 2장**. 테두리·그림자 없음. 카드 안에 카드를 넣지 않는다.
- 테두리는 입력칸·보조 버튼·선택지(Choice)에만. 경고 띠(`AlertStrip`)는 상태 면 + 왼쪽 선 6 — 카드로 세지 않는다(화면당 1개).

## 3. 색 — v6 토큰 그대로 (새 색 금지)
파랑 primary = 주 행동·선택·지나온 선, 네이비 navy = 예측 선·지금 점, 앰버 warning/warningInk/warningSoft = 주의·위험 구간·신고, 초록 comfort = 낮음 단계 띠 글자, sub = 비교의 "안내 없이" 선(전에 쓰던 #8A94A3 직접 값은 지움). 라이트·다크 모두 같은 토큰.

## 4. 화면별 영역 비율 (전체 창 FULL 기준, 1/2·1/3 창은 같은 순서로 위아래)
| 화면 | 가장 중요한 한 가지 | 영역 비율 | 카드 | 그림 |
| --- | --- | --- | --- | --- |
| 주행(분할 1/3·1/2) | 다음 쉼표까지 시간(수치) | 한 열: 맨 위 한 장(있을 때) · 평소 면 · 말하기 버튼 | 2 (맨 위 한 장 + 평소 면) | 사진 원 40 |
| 출발 전 | 출발 버튼 + 체크 n/3 | 좌 60(인사·반려견·체크) / 우 40(경로·예상 쉼표·출발) | 1 | 사진 원 96 |
| 프로필 편집 | 이름(제목) | 좌 34(사진·요약) / 우 66(입력) | 2 | 사진 원 140 |
| 온보딩 | 단계 제목 | 한 장, 그림은 단계 2만 16:9 | 1 | 1 |
| 설정 | 안내 빈도 | 좌 50 / 우 50 (구분선 목록) | 2 | 없음 |
| 쉼표(정차) | 쉬는 시간(수치) | 좌 40(지금 상태·행동 버튼) / 우 60(돌보기·할 일) | 2 | 없음 |
| 잠깐 대기 | 바깥 사람이 읽는 큰 글 | 한 장 가운데(v9 그대로) | 1 | 없음 |
| 긴급 도움 | 바로 동물병원 찾기 / 경고 띠 | 좌 66(카드·가장 가까운 병원) / 우 34(관련 안내) | 2 | 없음 |
| 동물병원 목록·사전 접수 | 가장 가까운 병원 거리·도착(수치) | 좌 55(목록) / 우 45(접수·연락) | 2 | 없음 |
| 하차 확인 | "콩이 내렸나요?"(제목) | 한 장 가운데, 사진 원 180 | 1 | 1 |
| 도착 요약 | 이동 거리·시간(수치 4칸) | 한 장 가운데, 최대 폭 1200 | 1 | 없음 |
| 리포트 | 요약 수치 | 위 요약 줄 / 좌 44(타임라인) · 우 56(그래프 ≤ 40% 높이 + 공유) | 2 | 없음 |
| 주행 자극 보기 | 지금 지수(수치) | 위 수치 3개 / 그래프(높이 ≤ 40%) / 근거·고정 문구 | 1 | 없음 |
| 고갯길 비교 | 최고값 차이(수치) | 위 수치 3개 / 그래프 / 보조 | 1 | 없음 |
- 사진·그림 비율: 반려견 = 원(1:1), 장소 사진 = 3:2, 일러스트 = 16:9. 좁고 긴 배치(폭:높이 1:2 이상) 금지.

## 5. 흔들림 그래프 (`StimulusChart` — 주행 자극 보기 · 리포트 자세히 보기의 같은 축 규칙, 고갯길 비교는 같은 세로축)
- **가로 = 시간 축**: 지나온 10분 + 지금 → 20분 뒤, 5분 눈금, 레이블 "−10분 · 지금 · 5분 · 10분 · 15분 · 20분"(보조).
- **세로 = 0~100**: 40·70 눈금, 낮음(0~40)·보통(40~70)·높음(70~100) 배경 띠(높음 = warningSoft, 보통 = surfaceAlt, 낮음 = 바탕), 오른쪽 끝에 단계 이름(보조).
- **선**: 지나온 값(엔진 1분 기록) = primary 실선, 예측(엔진 1분 21점) = navy 점선. 지금 위치 = 세로선 + 점.
- **위험 구간**: 엔진 예보의 굽은 길 시작·길이 → 그래프 위 앰버 면 + 위쪽 레이블 "12:05~12:17 굽은 길"(시각 = 신호 시계 + 분).
- **수치 3개(그래프 위)**: 현재 지수 · 예측 최고(시각) · 위험 구간(시작~끝 시각, 앞 거리). 값이 없으면 그 칸을 숨긴다.
- 그래프 높이 ≤ 화면 높이의 40%. 남는 자리는 수치·설명. **엔진이 준 값만** 그린다(점이 2개 미만이면 축과 "기록이 아직 없어요"). 고정 문구 "차량 흔들림 기준 · 반려견 측정 아님"(보조) 유지.
- 고갯길 비교: 같은 축에 두 선(안내 없이 = sub, 안내대로 = primary) + 수치 3개(최고값 차이 · 평균 차이 · 더 걸리는 시간).
- 리포트 자세히 보기(`TrendChart`): 가로 = 출발 뒤 시간, 같은 세로 띠·눈금, 흔들림 많은 구간 앰버 면, 휴식 회색 면, 신고 점선.
