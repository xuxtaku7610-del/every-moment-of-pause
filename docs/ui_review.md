## 실제 상태(시뮬레이터) 검증에서 찾은 것
- 발표 모드 점프 후 피로가 0부터 다시 쌓임 → `SignalRuntime.replays`로 건너뛴 구간을 엔진이 조용히 따라잡게 수정 (점프 후 "주의 57" 확인).
- 피로 "주의"인데 "지금은 편안해요"가 나옴 → 편안 단계에서만 제안 없음 화면, 그 외에는 다음 계획 쉼표 카드(버튼 없음).
- 서버가 꺼져 있으면 출발 준비 계획이 늦게 뜸 → 연결 타임아웃 1.5초.
- 남은 문제: 내장 샘플 휴게소가 12곳뿐이라 피로 주의 구간에 60분 안 후보가 없어 제안이 "일반 안내" 음성으로만 나감 → 단계 F에서 경부선 실제 휴게소 데이터로 교체.
